# InternCircle Task 2 — Personal Portfolio Landing Page

## Objective

Build a responsive personal developer portfolio using semantic HTML5 and CSS.

## Technologies

- HTML5
- CSS3

## Features

- Responsive navigation
- Personal hero section
- About section
- Skills section
- Projects section
- Contact section
- Responsive layout
- CSS Flexbox
- CSS Grid
- Mobile-responsive design
- Accessible semantic HTML

## Project Structure

```
Task-02/
├── assets/
│   └── profile1.png
├── index.html
├── README.md
└── style.css
```

## How to Run

1. Open `index.html` directly in any modern web browser (e.g. Chrome, Firefox, Safari, Edge).
2. Alternatively, serve using a lightweight local development server such as VS Code Live Server or Python's HTTP server:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000` in your browser.
